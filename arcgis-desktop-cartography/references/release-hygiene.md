# 公开发布与本机信息清理

仅分享技能代码、原创方法摘要、许可明确的合成数据与经检查的输出。不要复制用户实际研究数据、服务器配置、历史日志、凭据、cookie、SSH文件或论文全文缓存。

## 路径可移植性与隐私是两项检查

本轮实测：`SaveAs(..., True, False)` 和 `IDataLayer2.RelativeBase` 能保存可用的相对数据路径，但MXD仍可能记住保存目录，栅格LYR可能带有绝对工作空间诊断字符串。文本搜索通过不代表二进制安全。

旧的空白系统模板还可能带入历史个人样式路径、Normal.mxt 引用和VBA库信息。本包改用 `IMapDocument.New` 新建文档并显式设置A4页面，不继承系统模板；不要直接替换MXD原始二进制中的字符串。

本包原生文件在一个临时的中性盘符下创建，该盘符指向任务输出目录。构建后移除盘符，复制整个 `synthetic/` 到另一目录，重开10个MXD和41个LYR。只有所有数据源解析到迁移后的根目录才算通过。文件中的中性盘符残留是构建元数据，用户打开此包不需要创建该盘符。

若采用此方法：先确认盘符未被占用，仅为当前任务建立映射，在 `finally` 中移除自己创建的映射；不要改动已有映射。无需移动或修改ArcGIS安装。也可以使用不含个人信息的专用构建目录。

扫描范围应包括UTF-8/ASCII以及两种对齐的UTF-16字符串、PDF元数据、压缩包清单、文档属性、PNG文本字段。检查个人目录、用户名、主机名、IP、远程地址、密钥格式和含凭据URL。记录文件名和问题类型，不在日志中打印潜在密钥。

本包保留真实论文作者与DOI来源信息；这些是学术署名，不应作为本机隐私删除。服务器连接的内部地址和账号则不属于本技能的公开内容。
