# 数据契约与审图规则

## 接入真实数据之前

|对象|最低必需信息|拒绝的混用|
|---|---|---|
|位置/坐标|已知源CRS、目标CRS、单位、必要的基准转换、检查点|猜EPSG；把Define Projection当坐标变换|
|连续栅格|量纲、日期/累计区间、原始分辨率、NoData、有效域、像元原点|对比图各自自动拉伸；对缺测补零|
|类别栅格/面|完整代码字典、互斥性、未分类值、转移/评分规则|对类别做双线性插值；未说明评分就共用高低图例|
|地形|水平CRS和垂直基准分别记录，水平/垂直单位|将高程背景当水动力结果|
|点位|稳定ID、采样角色、日期、测量/推断状态、域外点解释|训练点冒充独立验证点|
|变化|相同单位、参照期、差值方向、有效域交集|原始值与标准化值相减|
|不确定性|生成方法、区间/阈值定义、空间依赖假设|把模型差异、置信区间、p值互换|
|密度/面积|分母与单位、有效面积、投影适用范围|以角度格网个数冒充等面积密度|

示例数据的真实状态在 `assets/synthetic/data/data-provenance.json` 中：固定种子、虚构区域、EPSG:32650仅用于米制测试，虚构高程没有现实垂直基准。栅格300米、类别格网1公里、聚合格网3公里；粗格网边缘使用有效像元均值。`uncertain.shp` 是设计点纹，**不具有推断统计意义**。

## 导出前四项核算

1. **数值和图例对应**：分级断点单调、覆盖有效值、边界值恰好落入一类；连续色标的单位、端点和零点正确；月份1—12齐全。
2. **对比契约**：相同变量的比较面板具有相同CRS、范围和色限；不同单位的因子各自图例。面积/流量不得由单纯显示重采样计算。
3. **比例尺**：示例使用平面投影米，图上长度为 `距离米 / 数据框范围宽度米 × 数据框宽度毫米`。Python 2须显式浮点除法，避免短标尺变成0。这只是投影平面标尺，不承诺全球或长距离的地表比例恒定。
4. **来源和缺失**：有效0与NoData不同；训练/测试、模拟/实测、数据/装饰层的含义可辨。未计算区可使用单独掩膜而非只有透明度。

## 技术验收与视觉验收分开

技术验收：新开进程重开MXD、检查全部数据框的CRS和图层；将整个包复制到新目录后移除构建盘符，再重开全部MXD和LYR；所有数据源必须在新根目录内；重新导出PNG并比较像素。单纯文件非空不构成验收。

视觉验收：按最终纸张大小检查标签、色标、比例尺、点线可见性、裁剪、字形、黑白可读性及PDF接缝。科学地图没有一套固定的“顶刊风格”；根据期刊尺寸与图件用途决定字号和细节。

示例未执行真实空间推断、地形水文建模、全套色觉缺陷模拟或中文字体验证。英文ASCII导出已实测，不能推定旧版ArcMap在任意中文数据/路径上都正常。
